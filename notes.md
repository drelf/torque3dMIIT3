# Torque3D - Project Notes

## What is this?
Full clone of the Torque3D open-source game engine (MIT license), version 4.0.3.
Upstream: https://github.com/TorqueGameEngines/Torque3D

## Backup repo
https://github.com/drelf/torque3dMIIT3

## Background
This engine was used in a previous project to build a **virtual office** by embedding a web browser directly into the 3D engine. The original project code was never pushed to GitHub, but this backup preserves the base engine for future reference and development.

## Key info
- **Language**: C++ with TorqueScript
- **License**: MIT
- **Default branch**: `development`
- **Platforms**: Windows, macOS, Linux
- **Features**: PBR rendering, built-in networking, PhysX/Bullet physics, integrated editors

## For Dev2
To clone this locally:
```bash
git clone https://github.com/drelf/torque3dMIIT3.git ~/projects/torque3d
```
